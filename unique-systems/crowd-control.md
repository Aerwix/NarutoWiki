# 🔻 Crowd Control

### :zap: Stun

**Effect: The character will be blocked from all kind of actions.**

* \[:x:] Can not use jutsus.
* \[:x:] Can not move your character.
* \[:x:] Can not do basic attacks.

### :mute: Silence

**Effect: The character will be blocked from using any kind of jutsu.**

* \[:x:] Can not use spells&#x20;
* \[:white\_check\_mark:] Can move freely

### :deciduous\_tree: Root&#x20;

**Effect: The character will be not able to move or be pushed.**

* \[:x:] Cannot walk/move
* \[:white\_check\_mark:] Can use spells and basic attacks.

### 🛡️ Invulnerable

**Effect: The character will not receive any kind of damage.**
